Referencia de la API
====================

Documentación generada a partir de los docstrings del paquete ``kmc3d`` con
``sphinx.ext.autodoc`` y ``sphinx.ext.autosummary``, como en la última parte del
tutorial de Sphinx. Hay una página por módulo con una tabla resumen y, debajo, cada
función y clase. El enlace «[fuente]» de cada objeto lleva a su código.

Los nombres principales se pueden importar directamente desde ``kmc3d``
(``KMC3D``, ``SplitRates``, ``CrystalGraph``, ``Cell``, ``presets``, ``seeds``…).
El módulo privado ``kmc3d._paths`` y la copia de ``src/`` (ver
:doc:`codigo_reutilizado`) no se documentan aquí.

.. note::

   Los docstrings están escritos en un estilo cercano a Markdown. ``conf.py`` los
   adapta a reStructuredText al generar esta página, sin tocar el código.
